# ESP32 Joystick Monitor (JoystickPlot)

Живой график джойстика/сенсоров **ESP32 через COM-порт** на WinForms (.NET 8).
Программа читает строки вида `v1,v2,...` из последовательного порта и рисует
данные в реальном времени: обычный график по времени, полярный режим и 3D-траекторию.

## Требования

- Windows (приложение WinForms, `net8.0-windows`)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Сборка и запуск

```bash
dotnet build          # собрать
dotnet run            # собрать и запустить
```

Либо открыть папку проекта в Visual Studio / Rider и запустить как обычно.
Единственная зависимость — пакет `System.IO.Ports` (подтянется NuGet'ом автоматически).

## Как пользоваться

1. Подключи ESP32 к компьютеру по USB.
2. Нажми **«Обновить»** — в списке появятся доступные COM-порты.
3. Выбери порт и бодрейт (по умолчанию `115200`), нажми **«Подключить»**.
4. Данные пойдут на график автоматически.

> Если порт не открывается — закрой монитор порта в Arduino IDE / PlatformIO
> и другие программы, которые могут его занимать.

### Формат данных от ESP32

Каждая строка — числа через запятую, любое количество каналов:

```
12.4,-3.1,0.85
12.6,-3.0,0.87
...
```

Первая нечисловая строка с запятыми трактуется как **заголовок — имена каналов**:

```
X,Y,Z
```

После неё каналы в панели справа получат эти имена.

Важно: десятичный разделитель — **точка** (инвариантный формат).
Пример для ESP32 (Arduino):

```cpp
void setup() {
  Serial.begin(115200);
  Serial.println("X,Y");        // один раз — имена каналов
}

void loop() {
  float x = analogRead(34) / 4095.0f;
  float y = analogRead(35) / 4095.0f;
  Serial.printf("%.3f,%.3f\n", x, y);
  delay(10);
}
```

### Режимы отображения

Кнопка **«Режим»** переключает отрисовку:

| Режим | Что показывает |
|---|---|
| **Время** | Графики всех каналов по времени (общий масштаб) |
| **Полярный** | Два первых видимых канала как вектор: R (отклонение) и φ (угол) |
| **3D** | Три первых видимых канала как траектория в пространстве; вращение — перетаскиванием мышью |

### Панель каналов (справа)

- **Галочка** — показать/скрыть канал.
- **Цветной квадрат** — выбрать цвет канала.

### Прочее

- Кнопка темы переключает тёмную/светлую тему.
- На экране хранится история из **400 точек** на канал.
- Статус (порт, бодрейт, число каналов и точек) — в заголовке окна и под графиком.

## Структура проекта

```
JoystickPlot.csproj   — проект (.NET 8, WinForms, System.IO.Ports)
Program.cs            — весь код: интерфейс, чтение порта, отрисовка
```

## Возможные проблемы

- **«Не удалось открыть порт»** — порт занят другой программой (монитор Arduino IDE, PlatformIO и т.п.) или выбран неверный бодрейт.
- **Данных нет, но порт открыт** — проверь, что ESP32 реально шлёт строки с запятыми и что бодрейт совпадает.
- **Имена каналов не подхватились** — заголовок (`X,Y,Z`) должен прийти **до** числовых данных.
