# Serial Plotter (монитор COM-порта)

Живой график джойстика/сенсоров **ESP32 через COM-порт** на WinForms (.NET 8).
Программа читает строки вида `v1,v2,...` из последовательного порта и рисует
данные в реальном времени: обычный график по времени, полярный режим и 3D-траекторию.

## Требования

- Windows (приложение WinForms, `net8.0-windows`)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Сборка и запуск

```bash
dotnet build          # собрать
dotnet run            # собрать и запустить
```

Готовое приложение одним файлом (без установленного .NET на целевой машине,
без папок с языками и DLL — всё внутри exe, ~70 МБ):

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

Результат — `publish/SerialPlotter.exe`, можно копировать и запускать на любом Windows x64.

Либо открыть папку проекта в Visual Studio / Rider и запустить как обычно.
Единственная зависимость — пакет `System.IO.Ports` (подтянется NuGet'ом автоматически).

## Как пользоваться

1. Подключи ESP32 к компьютеру по USB.
2. Нажми **«Обновить»** — в списке появятся доступные COM-порты.
3. Выбери порт и бодрейт (по умолчанию `115200`), нажми **«Подключить»**.
4. Данные пойдут на график автоматически.

> Если порт не открывается — закрой монитор порта в Arduino IDE / PlatformIO
> и другие программы, которые могут его занимать.

### Формат данных от ESP32

Каждая строка — числа через запятую, любое количество каналов:

```
12.4,-3.1,0.85
12.6,-3.0,0.87
...
```

Первая нечисловая строка с запятыми трактуется как **заголовок — имена каналов**:

```
X,Y,Z
```

После неё каналы в панели справа получат эти имена.

Важно: десятичный разделитель — **точка** (инвариантный формат).
Пример для ESP32 (Arduino):

```cpp
void setup() {
  Serial.begin(115200);
  Serial.println("X,Y");        // один раз — имена каналов
}

void loop() {
  float x = analogRead(34) / 4095.0f;
  float y = analogRead(35) / 4095.0f;
  Serial.printf("%.3f,%.3f\n", x, y);
  delay(10);
}
```

### Режимы отображения

Кнопка **«Режим»** переключает отрисовку:

| Режим | Что показывает |
|---|---|
| **Время** | Графики каналов по времени (общий масштаб), либо XY-график, если на ось X выбран канал |
| **Полярный** | Два первых видимых канала как вектор: R (отклонение) и φ (угол) |
| **3D** | Три первых видимых канала как траектория в пространстве; вращение — перетаскиванием мышью. В этом режиме в тулбаре появляются настройки: селектор **«3D: без времени / t → X / t → Y / t → Z»** заменяет выбранную ось на время — тогда достаточно двух видимых каналов (они займут оставшиеся оси); чекбокс **«Вращение»** включает/выключает автоповорот сцены |

### Менеджер каналов (справа)

- **Галочка** — показать/скрыть канал.
- **Цветной квадрат** — выбрать цвет канала.
- **«Ось X»** — относительно чего строить график: **«Время»** или любой канал.
  Если выбран канал, режим «Время» превращается в XY-график: по горизонтали
  выбранный канал, по вертикали — остальные видимые. Канал на оси X помечается
  подписью «— ось X».

### Консоль (снизу)

Всегда видимый лог сырых строк, приходящих от источника (порта или симулятора),
с метками времени. Кнопки **«Пауза»** и **«Очистить»**.

### Симулятор

Кнопка **«Симулятор»** открывает окно виртуальных каналов — можно проверять
графики без железа. Для каждого канала настраиваются имя, форма сигнала
(синус, прямоугольник, пила, шум, постоянный, блуждание), частота, амплитуда
и смещение. **«Старт»** — данные текут в тот же конвейер, что и из COM-порта
(50 строк/с): их видно и на графике, и в консоли. Работающий симулятор
блокирует подключение к порту — активен всегда только один источник.

> Если нужен именно вывод в **настоящий виртуальный COM-порт** (чтобы данные
> видела любая сторонняя программа), поставь драйвер [com0com](https://com0com.sourceforge.net/)
> и подключись к его паре как к обычному порту — встроенный симулятор этот
> сценарий закрывает внутри приложения без установки драйверов.

### Прочее

- Кнопка темы переключает тёмную/светлую тему.
- На экране хранится история из **400 точек** на канал.
- Статус (порт, бодрейт, число каналов и точек) — в заголовке окна и под графиком.


## Возможные проблемы

- **«Не удалось открыть порт»** — порт занят другой программой (монитор Arduino IDE, PlatformIO и т.п.) или выбран неверный бодрейт.
- **Данных нет, но порт открыт** — проверь, что ESP32 реально шлёт строки с запятыми и что бодрейт совпадает.
- **Имена каналов не подхватились** — заголовок (`X,Y,Z`) должен прийти **до** числовых данных.
