# Serial Plotter (монитор COM-порта)

Живой график джойстика/сенсоров **ESP32 через COM-порт** на WinForms (.NET 8).
Программа читает строки вида `v1,v2,...` из последовательного порта и рисует
данные в реальном времени: обычный график по времени, полярный режим и 3D-траекторию.

## Требования

- Windows (приложение WinForms, `net8.0-windows`)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Сборка и запуск

```bash
dotnet build          # собрать
dotnet run            # собрать и запустить
```

Готовое приложение одним файлом (без установленного .NET на целевой машине,
без папок с языками и DLL — всё внутри exe, ~70 МБ):

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

В PowerShell обратный слэш `\` не работает как перенос строки — используй
одну строку или обратный апостроф `` ` ``:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
```

Результат — `publish/SerialPlotter.exe`, можно копировать и запускать на любом Windows x64.

Либо открыть папку проекта в Visual Studio / Rider и запустить как обычно.
Зависимости: `System.IO.Ports` (работа с COM-портом) и `SvgNet` (экспорт графика в SVG) —
обе подтянутся NuGet'ом автоматически.

## Как пользоваться

1. Подключи ESP32 к компьютеру по USB.
2. Нажми **«Обновить»** — в списке появятся доступные COM-порты.
3. Выбери порт и бодрейт (по умолчанию `115200`), нажми **«Подключить»**.
4. Данные пойдут на график автоматически.

> Если порт не открывается — закрой монитор порта в Arduino IDE / PlatformIO
> и другие программы, которые могут его занимать.

### Формат данных от ESP32

Каждая строка — числа через запятую, любое количество каналов:

```
12.4,-3.1,0.85
12.6,-3.0,0.87
...
```

Первая нечисловая строка с запятыми трактуется как **заголовок — имена каналов**:

```
X,Y,Z
```

После неё каналы в панели справа получат эти имена.

Важно: десятичный разделитель — **точка** (инвариантный формат).
Пример для ESP32 (Arduino):

```cpp
void setup() {
  Serial.begin(115200);
  Serial.println("X,Y");        // один раз — имена каналов
}

void loop() {
  float x = analogRead(34) / 4095.0f;
  float y = analogRead(35) / 4095.0f;
  Serial.printf("%.3f,%.3f\n", x, y);
  delay(10);
}
```

### Режимы отображения

Кнопка **«Режим»** переключает отрисовку:

| Режим | Что показывает |
|---|---|
| **Время** | Графики каналов по времени (общий масштаб), либо XY-график, если на ось X выбран канал |
| **Полярный** | Два первых видимых канала как вектор: R (отклонение) и φ (угол) |
| **3D** | Три первых видимых канала как траектория в пространстве; вращение — перетаскиванием мышью. В этом режиме в тулбаре появляются настройки: селектор **«3D: без времени / t → X / t → Y / t → Z»** заменяет выбранную ось на время — тогда достаточно двух видимых каналов (они займут оставшиеся оси); чекбокс **«Вращение»** включает/выключает автоповорот сцены |
| **FFT** | Спектр первого видимого канала (окно Ханна, БПФ до 4096 точек). В тулбаре: **«Частота, Гц»** — частота дискретизации (по умолчанию 50 Гц — скорость симулятора; для железа задай фактическую), **«Лог (дБ)»** — логарифмическая (дБ) или линейная шкала амплитуды. В шапке графика — частота и уровень пика |

### Зум, панорама, маркеры (режим «Время»)

- **Выделение левой кнопкой** — рамка zoom-to-region: обе оси принимают
  диапазон выделенной области (простой клик без протяжки — маркер A/B).
- **Средняя кнопка** (или левая при включённом зуме) — панорамирование.
- **Колесо мыши**:
  - **Ctrl + колесо** — зум обеих осей к курсору;
  - **Alt + колесо** — растяжение/сжатие по вертикали (только амплитуда,
    вокруг значения под курсором);
  - **Shift + колесо** — навигация влево/вправо;
  - просто колесо — вверх/вниз.
- **Двойной клик** — сброс вида и маркеров.
- **Клик по графику** ставит линейки измерений по очереди: первый клик —
  маркер **A**, второй — **B** (между ними показываются **Δt** в точках
  и миллисекундах и **ΔV** каждого видимого канала), третий начинает
  цикл заново. Клик работает в любом месте области графика — попадать
  по самой линии не нужно.

Автоокно показывает последние 400 точек и прижато к правому краю:
новые точки появляются справа, заполненное окно **прокручивается влево**.
История глубиной 10000 точек доступна зумом и панорамой.

### Менеджер каналов (справа)

- **Галочка** — показать/скрыть канал.
- **Цветной квадрат** — выбрать цвет канала.
- **«…»** — переименовать канал, задать толщину и тип линии
  (сплошная, штриховая, пунктир, штрих-пунктир), а также **сглаживание**:
  скользящее среднее или медианный фильтр с настраиваемым окном.
  Сглаживание рисуется отдельным полупрозрачным слоем поверх исходной линии.
- **«Ось X»** — относительно чего строить график: **«Время»** или любой канал.
  Если выбран канал, режим «Время» превращается в XY-график: по горизонтали
  выбранный канал, по вертикали — остальные видимые. Канал на оси X помечается
  подписью «— ось X».

### Тулбар

Первая строка — кнопки с выпадающими меню:

- **«Порт ▾»** — выбор COM-порта (галочка на текущем) и **«Обновить список
  портов»**. Рядом поле **«Бодрейт»** — можно выбрать из списка или ввести
  вручную (сохраняется между запусками).
- **«Подключить»** — открыть/закрыть порт.
- **«Режим ▾»** — выбор отрисовки: Время / Полярный / 3D / Спектр FFT.
- **«Симулятор»**, **«Пауза»**.
- **«Инструменты ▾»** — **«Диапазоны графика…»**: чекбоксы автоматического
  диапазона (как по умолчанию — по данным) и ручные мин/макс по амплитуде (Y)
  и по времени/оси X. В режиме «Время» «макс» по оси X — ширина окна в точках
  (показываются последние N точек из 10000). Там же **«Сброс вида и маркеров»**,
  **«Полный сброс»** (порт, графики, вывод), **«Сглаживание»** — глобальный
  фильтр для всех каналов: выкл (по умолчанию) / скользящее среднее / медиана
  с выбором окна; канал со своим сглаживанием (диалог «…») перекрывает
  глобальный режим. И подменю **«Тема»** (тёмная / светлая / киберпанк).

Вторая строка — настройки активного режима (видны только в своих режимах):
в 3D — ось времени и автоповорот, в FFT — частота дискретизации и шкала.

### Линейка и легенда

- При наведении курсора на график появляется **линейка**: пунктирные
  вертикальная и горизонтальная линии; слева — амплитуда по горизонтали,
  снизу — время (номер точки) или значение оси X, у курсора — значения
  всех видимых каналов в этой точке.
- **Легенда** (имя и текущее значение каждого канала) рисуется под графиком,
  чтобы не перекрывать линии.

### Консоль (снизу)

Всегда видимый лог сырых строк, приходящих от источника (порта или симулятора),
с метками времени. Кнопки **«Пауза»** и **«Очистить»**. Строка ввода
+ **«Отправить»** (или Enter) — отправка данных в открытый порт.

### Симулятор

Кнопка **«Симулятор»** открывает окно виртуальных каналов — можно проверять
графики без железа. Для каждого канала настраиваются имя, форма сигнала
(синус, прямоугольник, пила, шум, постоянный, блуждание), частота, амплитуда
и смещение. **«Старт»** — данные текут в тот же конвейер, что и из COM-порта
(50 строк/с): их видно и на графике, и в консоли. Работающий симулятор
блокирует подключение к порту — активен всегда только один источник.

> Если нужен именно вывод в **настоящий виртуальный COM-порт** (чтобы данные
> видела любая сторонняя программа), поставь драйвер [com0com](https://com0com.sourceforge.net/)
> и подключись к его паре как к обычному порту — встроенный симулятор этот
> сценарий закрывает внутри приложения без установки драйверов.

### Прочее

- Кнопка **«Пауза»** в тулбаре останавливает запись в каналы (график замирает,
  а сырые строки продолжают идти в консоль). Повторный клик — «Продолжить».
- **Правый клик по графику** — экспорт: снимок в **PNG** или векторный **SVG**
  (то, что на экране, без линейки курсора) и **экспорт данных в CSV**
  (столбцы — каналы, десятичный разделитель — точка). Перед экспортом
  предлагается **выбор отрезка «с .. по ..»** по оси X; если ось X — время,
  доступна и обрезка по Y (кадр ограничивается заданным диапазоном).
- **«Полный сброс»** (меню «Инструменты ▾») — сброс буферов порта,
  очистка всех каналов и консоли.
- **«Тема»** переключает темы по кругу: тёмная → светлая →
  **киберпанк** (неоновая: чёрный фон, циан/магента, по мотивам MathArt).
  Тема применяется ко всему интерфейсу, включая палитру каналов;
  по умолчанию включена киберпанк.
- **Настройки сохраняются** между запусками (`%AppData%/SerialPlotter/settings.json`):
  последний порт и бодрейт, тема, выбор оси X, частота дискретизации,
  а также имена, цвета, видимость, тип линий и сглаживание каналов.
  При переподключении каналы пересоздаются с сохранённой конфигурацией,
  пока устройство не пришлёт новый заголовок; после **перезагрузки
  контроллера** повторный заголовок обновляет имена автоматически —
  приложение перезапускать не нужно.
- На экране хранится история из **10000 точек** на канал.
- Статус (порт, бодрейт, число каналов и точек) — в заголовке окна и под графиком.

```
DataHub.cs           — приём строк от любого источника, разбор, хранение каналов

ConsolePanel.cs      — консоль сырых данных из порта
TimePlot.cs          — график по времени / XY-график: линейка, маркеры, зум-вид, слой сглаживания
FftPlot.cs           — FFT-режим: спектр канала, линейная/дБ шкала

PolarPlot.cs         — полярный режим
Plot3D.cs            — 3D-траектория

```

## Возможные проблемы

- **«Не удалось открыть порт»** — порт занят другой программой (монитор Arduino IDE, PlatformIO и т.п.) или выбран неверный бодрейт.
- **Данных нет, но порт открыт** — проверь, что ESP32 реально шлёт строки с запятыми и что бодрейт совпадает.
- **Имена каналов не подхватились** — заголовок (`X,Y,Z`) может прийти в любой
  момент: он обновит имена и в начале, и после перезагрузки контроллера.
